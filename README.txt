YOUR COLOR STORY — REVISED FILES

Included:
- index.html
- script.js
- style.css

How to apply:
1. Back up the current files in your GitHub repository.
2. Replace index.html, script.js, and style.css with these revised versions.
3. Keep your existing image assets and their filenames in the same folder (for example, intro-banner.png, eye.color-blue.png, and the other images referenced in index.html).
4. Commit and push the three updated files to GitHub Pages.

Main updates:
- Seasonal result scoring no longer uses preferred style mood/neutral/palette answers as evidence for choosing the season.
- Natural clues and reported color-response answers feed the Forward Chaining + Certainty Factor rules; style preferences are presented as styling guidance.
- Final result uses a more visual palette layout and shorter summary notes.
- Save my palette downloads a designed PNG summary.
- Share result uses the device share menu where available, otherwise copies the result text or opens a copy prompt.

Note: This bundle contains the three updated code files, not the image assets already used by your website. Keep those assets in your repository.
